# V4.2 — UI WebSekolahV1 + Backend V4

Versi ini menggunakan source UI `sdnlarangan11/websekolahv1` sebagai shell visual utama, bukan sekadar meniru gayanya.

- Topbar, navbar, hero, facts, profil, visi, program, berita, pengumuman, prestasi, galeri, kontak, dan footer mengikuti struktur V1.
- Logo default diganti dengan logo resmi SDN Larangan 11 yang diberikan pengguna.
- Logo tetap dapat diganti dari Admin melalui `logo_url`.
- Hero mengikuti tampilan V1 dan tetap dapat diganti melalui `hero_image_url`.
- Backend Supabase V3/V4 tetap aktif.
- Smart Sync, staging, Edge Function, upload media, rombel, ekstrakurikuler, jadwal, dokumen tetap dipertahankan.
