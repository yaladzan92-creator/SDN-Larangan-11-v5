## Setelah upload ke GitHub
1. Supabase SQL Editor → jalankan `sql/v4_3_patch.sql`.
2. Pastikan bucket `school-media` public.
3. Buka `/admin/` → Data Sekolah → isi sosial media → Simpan.
4. Edit/tambah ekstrakurikuler → Upload Foto → Simpan.
5. Buka website dengan hard refresh (Ctrl+F5).
